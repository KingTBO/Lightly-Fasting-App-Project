Design and plan · not built yet

Your moon and sun, on the home screen

A widget shows how your fast is going without opening the app: the same filling disc, the same big number, the same calm.

The web app cannot make real widgets

Browsers cannot put a widget on an Android or iPhone home screen. “Add to Home Screen” only adds an icon. Real widgets are written in native code (Android App Widgets, iPhone WidgetKit), so they come with the Android app. Below is the design; the build notes are in docs/widgets.md.

Small · 2×2

For a glance: the disc, time left, and when it ends. The whole widget opens the app. There is no button on it; ending a fast always means opening the app and holding.

Medium · 4×2

A bigger disc, the start and end times, and the plan. When you are ready to fast, or in the eating window, there is a Start fast button. There is never an End button.

Lock Screen · iPhone

iPhone Lock Screen widgets are single-colour, so they use only the disc and the time. They never show the plan name, streak or anything else. Android phones do not put third-party widgets on the lock screen; there the ongoing notification does the job, and on the lock screen it only says “Lightly”.

Second wave · the week, and styles

A week widget shows the streak and the seven dots (a cheat day is a hollow dot). Styles, such as colours that follow the sky, would be part of Lightly Plus later. The timer widgets themselves stay free.

How they behave

The number ticks by itself

The time uses the system’s own timer view, so the app does not have to run and it costs no battery. The disc moves on about every 10 minutes.

Start yes, End never

You can start from a widget when you are ready. Ending always means opening the app and holding, so a pocket tap can’t end it, and nothing urges you either way.

Private by default

Only the start time, the goal and the sunrise and sunset times are shared with the widget. No weight, email or coordinates. The lock screen never names the plan, and a rest period just says “Rest”.
